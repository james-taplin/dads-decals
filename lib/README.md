# Build-only references

`MultiplayerAPI.dll` comes from the [Derail Valley Multiplayer](https://github.com/AMacro/dv-multiplayer) 0.1.16.0-Beta release zip (API 1.1.0), licensed Apache-2.0 (see `MultiplayerAPI.LICENSE`). It's only used to compile `DadsDecals.Multiplayer.dll` and is **not** shipped in the Dad's Decals zip: the Multiplayer mod provides it at runtime.
